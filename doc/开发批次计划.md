# 开发批次计划（一期）

> 定位：把一期开发编排成**可交付验收的批次**的执行计划。规则/实现/验收的唯一权威分别是 `doc/PRD.md`、`doc/技术方案.md`、`doc/测试用例.md`——本文件只引用不复制。
> 用法：每个批次开工前读对应章节（见各批「依据」）；**批次进度状态记录在 `TODO.md`**（本文件不记状态）；新对话入口 = AGENTS.md → TODO.md → 本文件 → 相关文档。

## 批次完成定义（每批通用收口动作）

1. 该批功能可用，与 `doc/原型.html` 走查一致（原型未覆盖处按 PRD）；
2. 该批涉及模块的 `doc/测试用例.md` 用例通过，且文末**回归最小集**通过；
3. `cargo test` 与 `vitest`（相关或全部）通过；
4. `PROJECT_MAP.md`、`TODO.md`、`CHANGELOG.md` 已按 AGENTS 第 8 条刷新；
5. 未做超出本批范围的「顺手重构」；收口时提示提交（中文 commit；git init 暂缓至首次提交前）。

## 各批详细范围与验收动作

### P0 工程初始化
- 范围：Vite + React 18 + TS（前端在 `src/`）；Tauri 2 后端（`src-tauri/`）；vitest 冒烟用例；安装 zustand（决策 D12 已确认）；`.gitignore` 内容就位（`data\`、`node_modules\`、`dist\`、`src-tauri\target\`），`git init` 仍暂缓；IPC 最小命令打通（如 `ping` 往返）；`src-tauri/src/store/` 目录占位。
- 验收动作：`npm run build` 通过、`vitest run` 通过、`cargo test` 通过；`npm run tauri dev` 能弹出主窗口且前后端 IPC 可用（人工确认一次）。
- 注意：一期不引入任何网络类 crate（红线 1）；仅 tauri2/rusqlite(bundled)/serde 等既定依赖。

### P1 数据层 store 与 schema
- 范围：`schema_migrations` 版本管理 + v1 迁移（categories/items/field_defs/item_field_values/app_settings，含索引与 FK）；store 单连接 Mutex；归属判定（日历/待办集合）与待办排序（COALESCE 哨兵）等查询函数；数据校验入口；迁移/查询单测。
- 依据：技术方案 3.1、5.2。

### P2 分类模块
- 范围：后端 categories commands（list/create/rename/set_color/delete(mode)）+ 前端标签栏、色盘（11×6+自定义）、分类管理菜单、「未分类」固定与颜色、总览聚合。
- 验收：TC-CL-001~009；总览/未分类特例与原型一致。

### P3 事项模块（基础 CRUD）
- 范围：items commands（create/update/delete/get_detail/query_calendar/query_todo）+ 新增/详情编辑弹窗、删除二次确认、归属动态迁移、总览可编辑删除不可经工具栏新增。
- 验收：TC-IT-001~012（含 TC-IT-012 快捷入口预填由 P4 提供，P3 先保证弹窗与 CRUD）。

### P4 日历视图
- 范围：周/月网格（周一起始、前后月补齐、今日高亮）、`layout.ts` 横条布局纯函数 + vitest（跨格/截断/泳道/+N/按开始时间排序）、`+N` 浮层、**格内「+」快捷新建**（分类/总览可加、补齐格不加；总览弹窗带分类下拉）。
- 验收：TC-CAL-001~012；vitest 布局用例；与原型走查一致。
- 注意：排序键 `(segStart, start_time, segEnd, id)`，无时刻视为 00:00（A2/PRD 5.3 v1.4）。

### P5 待办视图
- 范围：待办区容器（按当前标签页过滤）、时间轴分组折叠（会话级记忆）、虚拟滚动、「长期规划」沉底（哨兵 9999-12-31）。
- 验收：TC-DUE-001~008；TC-FLD-014（条目只显示标题）。

### P6 自定义字段
- 范围：字段管理 UI（增删改名/改类型/选项维护/排序）、六类型控件渲染与校验、(from,to) 转换矩阵表驱动实现 + 穷举单测、切分类字段值保留（按模板过滤展示）。
- 验收：TC-FLD-001~017；`cargo test` 矩阵全路径。
- 注意：文本/数字/日期→单选/多选按历史值去重生成选项（PRD 6.6 v1.2）。

### P7 撤销/重做与进程
- 范围：undo 双栈 + 行级/级联/整库快照（导入快照剔除 mail_config、大快照落 `data\undo_tmp`，D10）；Ctrl+Z/Y 与按钮兜底；单实例互斥（D9）；启动 WebView2 runtime 检测与环境变量设置（D11 运行部分）。
- 验收：TC-UNDO-001~009、TC-ENV-001。

### P8 备份
- 范围：export/import（带 format_version 的单 JSON）、导入语义校验（标题非空/日期成对/结束不早于开始/单选在选项内）、二次确认、导入前整库快照入撤销栈。
- 验收：TC-BAK-001~006。

### P9 一期收尾
- 范围：回归最小集 17 条全过；`cargo test` + `vitest` 全量绿；`tauri build --bundles none` 产出便携目录并说明 `webview2\` 捆绑步骤（D11 打包部分）；README（绿色目录/WebView2/手动重试/备份）；CHANGELOG 一期条目；PROJECT_MAP/TODO 终态；对照 AGENTS 第 9 节 DoD。
- 备注：WebView2 Fixed Version Runtime 由微软官网下载 zip 解压放入 exe 同目录 `webview2\`（体积 +~180MB，用户已确认放宽）。

## 交接约定
- 批次中途若对话上下文不足：**先按「批次完成定义」收口**（至少刷新 TODO 记录进度与下一步），再开新对话继续。
- 每批之间的新对话：读 `AGENTS.md` → `TODO.md`（当前批次/进度）→ 本文件（该批范围与验收）→ PRD/技术方案/测试用例对应章节。

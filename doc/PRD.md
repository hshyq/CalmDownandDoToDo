## 1. 产品概述

### 1.1 一句话定位
面向个人用户的 Windows 桌面「日历 + 待办」二合一记录工具：按分类记录事项，根据时间字段完整性自动归入日历或待办展示。数据全本地、默认离线、免安装。

### 1.2 目标用户与核心场景
- 个人用户在电脑前记录生活、工作、娱乐、学习等各类事项。
- 有明确起止日期的事项看日历；没有起止日期（仅有截止时间或完全没有时间）的事项看待办清单。

### 1.3 产品名
暂用「日历待办工具」，正式名称待定（命名不影响本 PRD 的功能定义）。

### 1.4 版本划分
- **一期**：分类记录、日历视图、待办视图、自定义字段、撤销重做、数据备份。**完全离线，零网络代码。**
- **二期**：邮箱绑定、事项提醒、同步发送邮件、应用内提醒弹窗。默认离线，仅在用户显式操作时联网。

## 2. 名词定义

| 名词 | 定义 |
| :--- | :--- |
| 事项 | 一条记录，由标准字段与自定义字段值组成 |
| 分类 | 事项的归属容器，有名称与颜色，如生活/工作/娱乐/学习 |
| 日历 | 视图区域：按周/月展示"开始+结束时间完整"的事项 |
| 待办 | 视图区域：按截止时间升序展示"开始/结束时间不完整"的事项 |
| 横条 | 日历格子上代表一个事项的圆角矩形，内容为事项标题，背景为分类颜色 |
| 总览 | 顶部固定标签页，汇总所有分类的事项；无工具栏新增按钮，但日历格「+」可新增（弹窗需选择所属分类，见 6.3） |
| 未分类 | 底部固定标签页，承接被删除分类下的事项 |
| 哨兵值 99991231 | 无截止时间事项的内部排序值，界面上显示为「长期规划」 |

## 3. 整体布局

三栏结构，从左到右：

```
┌────────┬──────────────────────────────────────┬──────────────┐
│ 标签栏   │ 工具栏：‹ › [今天]  [周|月]  2026年8月  [+ 新增事项]   │  待办区        │
│ (窄固定) ├──────────────────────────────────────┤ (窄固定)       │
│ 总览     │                                      │ ● 2026-08    │
│ 生活     │                                      │   ○ 事项A     │
│ 工作     │           日历区                       │   ○ 事项B     │
│ 娱乐     │   周视图：1行×7列 / 月视图：5~6行×7列      │ ● 2026-09    │
│ 学习     │   （事项横条跨格显示）                    │   ○ 事项C     │
│ …       │                                      │ ● 未设截止     │
│ 未分类   │                                      │   ○ 事项D     │
│─────────│                                      │              │
│ ⚙ 设置   │                                      │              │
└────────┴──────────────────────────────────────┴──────────────┘
```

- **标签栏**：固定宽度约 160px。顶部固定「总览」；中部为用户分类（按排序值排列）；底部固定「未分类」；最底部「⚙ 设置」入口（一期仅含数据备份页签，二期扩展，见 8.1）。
- **日历区**：占剩余宽度主体。顶部工具栏含：上/下周期切换、回到今天、周/月切换、当前年月标题、新增按钮（仅分类页与未分类页显示，总览页不显示）；日历格「+」快捷入口见 6.3。
- **待办区**：固定宽度约 280px。展示当前标签页范围内的待办（分类页=该分类的待办；总览=全部分类的待办；未分类页=未分类的待办）。

## 4. 数据模型

### 4.1 分类

| 属性 | 说明 |
| :--- | :--- |
| 名称 | 必填，≤20 字符；标签栏内超宽截断显示省略号（存储完整全文） |
| 颜色 | 从色盘点选或自定义；**不做重复校验**，允许多个分类同色 |
| 排序 | 整数，决定标签栏顺序；新建分类排到最后 |
| 类型 | 普通 / 固定（总览、未分类为固定类型，不可删除、不可重命名） |

- **预置分类**：生活、工作、娱乐、学习（首次启动自动创建），均为普通分类，可改名/改色/删除。
- 新建分类时自动分配色盘标准行（第 4 行）中当前使用最少的颜色（仅为省事的默认值，可随意改，不校验重复）。
- **未分类**：不可删除、不可重命名；可以设置颜色、可以新增/编辑/删除事项、可以管理自定义字段模板（与普通分类完全一致，无特例）。
- **总览**：不是分类，是聚合视图；没有颜色、没有字段模板；无工具栏与字段管理入口，可经日历格「+」快捷新增（弹窗需选分类，见 6.3）。

**分类色盘**（飞书式在线表格字体色盘，原型已实现）：11 列 × 6 行；第 1 行与第 4 行颜色相同，第 2~6 行每列由浅到深、同列同色系；底部「更多颜色」支持自选颜色或输入 HEX / RGB 值。

### 4.2 事项标准字段

| 字段 | 必填 | 取值形态 | 说明 |
| :--- | :---: | :--- | :--- |
| 所属分类 | 新增时隐含 | 引用（分类） | **新增弹窗不显示该字段**（默认=当前分类页的分类）；**总览页无当前分类，新增弹窗显示该字段**（默认第一个分类）；**编辑弹窗显示且可修改**为任意分类或未分类 |
| 标题 | ✅ | 单行文本 | ≤100 字符 |
| 描述 | ❌ | 多行文本 | 选填 |
| 开始时间 | ❌ | 日期+可选时刻 | 格式 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm` |
| 结束时间 | ❌ | 同上 | 日期部分不得早于开始时间（校验提示） |
| 截止时间 | ❌ | 同上 | 独立于开始/结束时间，用于待办排序与分组；**日历事项的截止时间仅在详情弹窗中展示**，不参与日历/待办区的排序与展示 |

**时间语义**：
- 「时间完整」= 开始时间与结束时间**都有值**（时刻缺失视为该日 00:00）。
- 日历格子归属只看**日期部分**；时刻仅用于：详情展示、日历格内横条排序（按开始时间）、待办同日内排序。
- **日历格内**多个事项按开始时间升序自上而下堆叠，无时刻视为 00:00；开始时间相同按创建先后排列（见 5.3）。
- **待办组内**排序见 5.2（按截止时间）。

### 4.3 自定义字段（分类级模板）

| 属性 | 说明 |
| :--- | :--- |
| 名称 | 必填，可修改 |
| 类型 | 单行文本 / 多行文本 / 数字 / 日期 / 单选 / 多选（六种） |
| 选项列表 | 仅单选/多选类型有；可增删改选项 |
| 排序 | 整数，决定弹窗中的字段展示顺序 |

- 字段模板挂在**分类**上：该分类下所有事项共用同一套字段定义。
- 字段值挂在**事项**上，按字段 ID 动态存取。
- 总览页无字段模板；未分类页与普通分类一致。
- **切换事项所属分类后**：原分类的字段值**保留在数据中但不再显示**；切回原分类时恢复显示。弹窗中的字段区按当前所属分类的模板实时渲染。
- 所有日历视图（日历横条、待办条目）**只展示事项标题**，自定义字段只在弹窗中出现。

## 5. 核心规则

> 本章是产品正确性的核心，全部条目在 `doc/测试用例.md` 中有用例覆盖。

### 5.1 日历/待办归属规则

| 开始时间 | 结束时间 | 归属 |
| :---: | :---: | :---: |
| 有 | 有 | **日历**（不论是否有截止时间） |
| 有 | 缺失 | **待办** |
| 缺失 | 有 | **待办** |
| 缺失 | 缺失 | **待办** |

- **动态迁移**：编辑补全开始+结束时间 → 立即从待办移入日历；编辑清空任一 → 立即从日历移入待办。
- 一个事项同一时刻只出现在日历、待办其中之一。

### 5.2 待办排序与时间轴分组
- 按截止时间升序排列；**无截止时间视为哨兵值 99991231，永远排在最末**，分组名显示「长期规划」而不是 9999 年。
- 截止时间属于同一年月的事项构成一个分组；组内按截止时间（日期+时刻）升序，时刻相同再按创建时间升序。
- 待办区有纵向时间轴：一条竖线贯穿，每组一个**空心圆点**，圆点旁标注年月（如 `2026-08`）；「长期规划」组在时间轴最末端。
- 点击圆点或年月行 → 折叠/展开该组，**默认全部展开**。折叠状态仅在当前会话内记忆，重启软件后恢复默认展开。

### 5.3 日历显示规则
- 周视图：1 行 × 7 列（周一~周日）；月视图：5~6 行 × 7 列。
- **周一为每周第一天**（周视图与月视图一致）。
- 月视图首日不是周一 / 末日不是周日时，用上月/下月日期补齐整行；补齐格子中的事项正常显示，该格子的日期数字弱化显示（灰色）。
- 事项以**横条**展示：内容**仅标题**，背景为所属分类颜色（圆角矩形）；标题过长截断，悬停显示全文。
- 跨日事项：从开始日期到结束日期**连续跨格**显示；跨周/跨月时在当周/当月范围内截断显示。
- 同一天多个横条重叠时纵向堆叠（泳道排布）；超出格子可容纳数量时末尾显示「+N」，点击「+N」弹出当日事项浮层列表，点击其中条目打开详情。
- 同一格内多个横条自上而下按**开始时间**升序排布，无时刻视为 00:00；开始时间相同按创建先后排列。
- 「+N」浮层当日事项列表与格内同序：按开始时间升序、无时刻视为 00:00、相同按创建先后。
- 今日格子有高亮标记。
- **拖拽改期**（v1.8）：
  - 拖动日历横条放到目标日期格：起止日期按「目标格日期 − 原开始日期」的天数偏移整体平移，**跨度与已填时刻保持不变**；保存后按新日期重新显示。操作计入撤销栈（Ctrl+Z 可回退）。
  - 拖动待办区条目放到日历日期格：该事项开始日期=结束日期=目标格日期（已填时分保留），按 5.1 归属规则立即移入日历；操作计入撤销栈。
  - 拖拽仅改开始/结束日期，不修改标题、描述、截止时间、所属分类与自定义字段值。

### 5.4 颜色规则
- 事项颜色 = **标题文本的背景色**（圆角矩形）；日历横条与待办条目使用同一规则。
- 总览页的事项颜色跟随各自所属分类的颜色；未分类事项颜色 = 未分类的颜色（默认灰色 `#9E9E9E`）。

## 6. 界面与交互详细需求

### 6.1 标签栏
- 顶部固定「总览」；其下按排序展示所有普通分类；底部固定「未分类」；最底部「⚙ 设置」。
- 标签页名称**横排**显示，超出宽度截断并显示省略号，悬停显示全文。
- 当前选中的标签页高亮。
- 分类标签（含未分类）hover 时右端出现「⋮」设置按钮，点击弹出菜单：
  - 普通分类菜单：**设置颜色 / 重命名 / 删除**；
  - 未分类菜单：仅**设置颜色**；
  - 总览无「⋮」按钮。
- 不使用右键菜单实现（已否决右键方案）。

### 6.2 分类管理
- **设置颜色**：色盘点选或「更多颜色」自定义（HEX / RGB），即时生效，不做重复校验；一次确认计为一步撤销。
- **重命名**：弹输入框；不可为空，≤20 字符。
- **删除**：
  - 分类下**无事项**：确认弹窗「确定删除分类【X】？」→ 删除。
  - 分类下**有事项**：弹窗二选一：①「连同 N 条事项一起删除」（二次确认后级联永久删除）②「事项移入未分类」（分类删除，事项完整保留并改挂未分类）。
  - 被删除分类的字段模板一并删除，**其字段值随模板级联清除**（决策 A，技术方案 3.1）；移入未分类的事项**标准字段数据完整保留**，自定义字段因模板已删不再显示。

### 6.3 新增事项
- 入口：分类页/未分类页工具栏「+ 新增事项」按钮；**总览页无此按钮**。
- 快捷入口：鼠标悬浮日历**日期格**（周/月视图，含月视图前后月补齐格，v1.8）时，格内右上角出现「+」；点击打开新增弹窗，**开始时间与结束时间的日期均默认=该格日期**（时刻为空，v1.8）。**分类页/未分类页/总览页均显示**该入口；总览页点击后弹窗显示「所属分类」下拉（默认第一个分类），分类页/未分类页不显示（默认=当前分类）。
- 弹窗字段：标题*、描述、开始时间、结束时间、截止时间、当前分类的自定义字段。**不显示所属分类字段**（默认=当前分类）。
- 校验：标题必填；结束时间的日期部分不得早于开始时间。
- 保存后按 5.1 规则决定进入日历还是待办。

### 6.4 事项详情弹窗（查看/编辑/删除）
- 点击日历横条或待办条目打开。
- 展示全部字段：所属分类（下拉，可改为任意分类或未分类）、标题、描述、开始/结束/截止时间、当前所属分类模板的自定义字段及其值。
- 可编辑任意字段；保存后应用 5.1 归属规则（可能发生日历⇄待办迁移）。
- 「删除」按钮：二次确认后永久删除。
- **总览页可编辑与删除；无弹窗新增能力，新增仅经日历格「+」入口**（弹窗需选分类，见 6.3）。

### 6.5 自定义字段管理
- 入口：分类页/未分类页工具栏「字段管理」按钮（总览无）。
- 支持操作：新增字段、修改名称、**修改类型**、维护选项（单选/多选）、**删除字段**、调整排序。
- **删除字段**：二次确认，明确提示「将丢失该字段下所有已填写数据」。
- **修改类型**：按 6.6 转换矩阵处理该字段的全部历史数据。
- **修改选项列表**：已填值不在新选项内的部分被清空（单选：整个值清空；多选：仅移除失效的选中项）。

### 6.6 字段类型转换矩阵（飞书式校验：能转则转，不能转清空）

| 从 ↓ 到 → | 单行文本 | 多行文本 | 数字 | 日期 | 单选 | 多选 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **单行文本** | — | 原值保留 | 可解析为数字则转，否则清空 | 可解析为日期则转，否则清空 | 历史值去重生成选项，原值保留 | 同左，保留为单元素多选 |
| **多行文本** | 原值保留 | — | 同上 | 同上 | 同上 | 同上 |
| **数字** | 转字符串，无损 | 转字符串，无损 | — | 字符串化后可解析为日期则转，否则清空 | 历史值字符串化去重生成选项，原值保留 | 同左，保留为单元素多选 |
| **日期** | 转字符串，无损 | 转字符串，无损 | 清空 | — | 历史值字符串化去重生成选项，原值保留 | 同左，保留为单元素多选 |
| **单选** | 转字符串，无损 | 转字符串，无损 | 字符串化后可解析为数字则转，否则清空 | 字符串化后可解析为日期则转，否则清空 | — | 值在新选项中则保留为单元素，否则清空 |
| **多选** | 选中项按序以「、」连接 | 同左 | 连接后可解析为数字则转（通常清空） | 连接后可解析为日期则转（通常清空） | 保留第一个仍在新选项中的选中项，否则清空 | — |

- 「可解析为数字」= 去除首尾空格后是合法整数或小数。
- 「可解析为日期」= 符合 `YYYY-MM-DD` 或 `YYYY-MM-DD HH:mm` 且为真实存在的日期。
- 「文本/数字/日期 → 单选/多选」：此类字段原本**没有选项列表**，转换时将该字段全部历史值字符串化并**去重生成选项列表**，每条事项的原值保留（多选保留为单元素多选），零数据丢失。
- 「单选 ⇄ 多选」及选项列表的日常维护（见 6.5）仍按**已有选项列表**校验，不适用上一条。
- 转换在用户确认修改类型时一次性完成，过程不可见、结果即生效（计入撤销栈）。

### 6.7 撤销与重做
- **Ctrl+Z** 撤销，最多 **10 步**（超出丢弃最旧的一步）；**Ctrl+Y** 重做（同 Word/Excel 习惯）。
- 覆盖范围：事项的增/改/删；分类的增/删/改名/改色（含删除分类时的级联删除或移入未分类的完整效果）；字段的新增/删除/改名/改类型/选项变更；备份导入（导入前的状态可撤销恢复）。
- 撤销粒度：一次弹窗保存/确认 = 1 步；颜色点选确认 = 1 步；文本框逐字输入不占步数。
- **仅当前会话有效**：关闭软件重新打开后撤销栈清空。
- 快捷键在焦点位于文本输入框内时不生效（此时为文本级撤销）；界面提供撤销/重做按钮兜底。
- 纯视图状态（折叠/展开、周月切换、当前标签页）不占撤销栈。

### 6.8 数据与备份
- 数据库文件：exe 同目录 `data\calendar.db`（SQLite）。启动时检测目录不可写则弹提示，引导用户将 exe 移至可写目录。
- **导出备份**：一键导出全库（分类+事项+字段定义+字段值+提醒(二期)+设置）为带版本号的单 JSON 文件，文件名含导出日期；**不含邮箱授权码**（DPAPI 密文与机器绑定，换机无法解密）。
- **导入备份**：选择 JSON 文件 → 二次确认「将覆盖当前全部数据」→ 整库替换（计入撤销栈，可撤销回导入前状态）。

## 8. 二期功能

### 8.1 设置页
- 入口：标签栏最底部「⚙ 设置」。
- 一期即显示入口，一期范围内仅含「数据备份」页签；二期的「邮箱绑定」「提醒发送记录」页签随二期启用。

### 8.2 邮箱绑定
- 表单：SMTP 服务器、端口、加密方式（SSL/TLS 或 STARTTLS）、邮箱账号、SMTP 授权码、发件人显示名称。
- 「发送测试邮件」按钮：向自己的邮箱发一封测试邮件验证配置。
- 授权码使用 Windows DPAPI 加密后存本地数据库；不以明文落盘、不出现在日志。
- 可随时解绑（清除配置）。
- 合规结论：绑定用户本人邮箱、给自己发提醒、数据全本地，不涉及第三方个人信息收集，**合法**。
- 用户需自行在邮箱服务商处开通 SMTP 并获取授权码（软件提供引导说明）。

### 8.3 提醒设置
- 事项详情弹窗内增加「提醒」区块：可为事项添加**多条**提醒，每条 = 提醒时间（日期+时刻）+ 提醒内容（默认预填事项标题）。
- 提醒独立于事项的开始/结束/截止时间。

### 8.4 同步与发送
- 工具栏「同步提醒」按钮（绑定邮箱后可用）。
- 点击同步：扫描全部提醒，把**未来 30 天内**的提醒生成待发计划（本地队列）；界面显示上次同步时间。
- 同步之后新设置/修改的提醒，需**再次同步**才会进入发送计划（界面明确提示）。
- 托盘常驻：软件最小化到托盘保持运行；后台定时扫描队列，到点执行：
  - 弹出**应用内提醒弹窗**（置顶小窗）：显示提醒内容与事项标题，按钮：「稍后 10 分钟 / 关闭」。**点击关闭即视为已处理，不再弹出**（不提供「标记完成」）。
  - 该提醒在发送计划内且邮箱已配置：经 SMTP 直发邮件给自己。邮件标题=提醒内容，正文含事项标题、时间与提醒内容。
- 到点时若电脑关机/软件未运行：该封提醒邮件错过，**不补发**，状态置「过期」（过期记录不可手动重试）；下次启动时检测过期未发提醒，弹窗汇总告知「有 N 条过期提醒」。
- 发送失败置为「失败」，**不自动重试**；可在「提醒发送记录」页签对失败记录**手动重试**（重试成功置「已发」）。页签可查看每条计划的状态（待发/已发/失败/过期）。
- 设计决策说明：原设想"生成草稿到邮箱+邮箱定时发送"因草稿无法携带定时属性（邮箱产品机制限制）而弃用，改为本地到点直发；详见 `doc/技术方案.md` 关键决策记录。

### 8.5 离线原则（二期同样遵守）
- 默认零联网：未绑定邮箱时，二期功能不产生任何网络请求，也不影响一期使用。
- 联网仅发生在两个显式动作：①「发送测试邮件」；②同步计划内提醒到点发送。连接全程 TLS 加密。
- 其余任何时刻（启动、浏览、增删改查、备份导出）均无网络行为。

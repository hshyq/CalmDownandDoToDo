# CalmDownandDoToDo

> 先冷静，再一件件做完——本地优先的日历 + 待办桌面工具。
>
> Windows 桌面「日历 + 待办」二合一记录工具：按分类记录事项，根据时间字段完整性自动归入日历或待办展示。**免安装单 exe、绿色便携、数据全本地、默认离线。**

当前版本 v0.3.10（一期全量 + 拖拽改期 + 墨刀式色盘 + 日期类型 + 滚轮切换周期 + 自定义字段全局化 + TXT 导出 + 列表视图）。

## 功能特性

- **分类记录**：预置生活/工作/娱乐/学习，可自定义增删改；墨刀式低饱和色盘（SV 取色面板 + HEX 自定义）、色块文字颜色随背景亮度自适应、重命名、删除（非空分类可选「连同事项删除」或「事项移入未分类」）
- **日历视图**：周/月切换、周一起始、月视图前后月补齐、分类色圆角横条显示标题、跨格/跨周/跨月、同日堆叠与「+N」浮层、格内「+」快捷新建（总览可新增并选分类；开始与结束日期自动预填当天，补齐格同样支持）、年月标题点击选择年月/周、鼠标滚轮切换上/下周期
- **拖拽改期**：日历横条拖到目标格按偏移平移起止日期（跨度与时分不变）、横条两端拖拽单独改开始/结束日期；待办条目拖到日历格一键变为当日事项；均可 Ctrl+Z 撤销
- **拖拽转待办**：日历横条拖到待办面板，结束日期自动转为截止日期（开始保留），事项即从日历转为待办，Ctrl+Z 可撤销
- **列表视图**：全部事项一览表（分类/标题/归属/开始/结束/截止+自定义字段动态列），按结束日期升序统一排列；支持标题搜索与日期范围筛选（一周/一月/两月/自定义），「筛选/重置」按钮控制应用；点击行编辑，填了什么显示什么
- **日期类型**：每天日期数字下方以色条标注生效类型（工作日蓝/休息日灰/假日红，含默认推算），点击色条循环切换；可把任意日期指定为其他类型（调休上班、法定假日，假日日期数字红色）；工具栏「日期类型」月历弹窗批量管理，Ctrl+Z 可撤销；今天的格子整体按当天类型染色，一眼定位
- **导出 TXT**：设置 → 数据备份 → 「导出 TXT」，按时间范围（默认当前月+下一月，可一键选一周/一月/两月内）把事项导出为文本清单（日历含起止日期、待办含截止日期）
- **事项弹窗**：新增/编辑/删除，描述多行输入，日期/时刻支持分段键入（年最多 4 位自动跳段）或点图标弹选择器；点击弹窗以外、应用窗口以内的区域即关闭且不保存（等同取消）；切换到其他窗口再切回，编辑内容保留
- **待办时间线**：待办列表中今天的位置显示红色时间线，区分已到期与未来
- **待办视图**：按截止时间升序、无截止沉底「长期规划」；纵向时间轴按年月分组、可折叠；条目右侧显示截止日的「日」数字；列表中显示红色「今天」时间线区分已到期与未来
- **归属规则**：开始+结束时间完整 → 日历；否则 → 待办；编辑时自动双向迁移
- **自定义字段**：全部分类通用（定义全局 + 按分类配置可见），单行/多行文本/数字/日期/单选/多选；事项切换分类后字段数据完整保留；改类型按「能转则转、不能转清空」迁移历史值；文本/数字/日期转选项类自动按历史值生成选项
- **拖拽转待办**：日历横条拖到待办面板，结束日期自动转为截止日期
- **撤销/重做**：Ctrl+Z 最多 10 步、Ctrl+Y 重做（仅当前会话）；导入备份可撤销回导入前
- **数据备份**：设置 → 数据备份，一键导出（系统另存为，默认文件名含日期）/ 导入（覆盖前二次确认，语义校验拒绝坏文件）

**二期（规划）**：邮箱绑定（SMTP + Windows DPAPI 加密授权码）、事项提醒 + 到点弹窗 + SMTP 直发、同步与过期汇总。完整需求见 [doc/PRD.md](doc/PRD.md)。

## 安装与启动（绿色便携目录）

1. 解压发布包得到一个目录，内含：`日历待办工具.exe`、`webview2\`（可选，见下）、`README.md`。
2. 双击 `日历待办工具.exe` 即可使用：**无需安装、无需管理员权限、无需联网**。

### 关于 WebView2（重要）

界面依赖 WebView2 运行时，两种方式二选一：

- **推荐（随包携带，零依赖）**：从微软官网下载 *WebView2 Runtime Fixed Version*（x64 zip），解压后把其中含 `msedgewebview2.exe` 的文件夹改名为 `webview2`，整体放到 exe 同目录。程序启动时检测到该目录会自动使用固定版（无需预装）。
- **系统自带**：若未放 `webview2\`，程序使用系统已安装的 Evergreen WebView2（Windows 10/11 多数自带；缺失时首次启动会提示）。

### 数据与安全

- 数据库：exe 同目录 `data\calendar.db`（运行期自动生成）。**数据随目录走：整个目录拷贝即迁移，删除目录即卸载干净**。
- 请把程序放在**可写目录**（如桌面、文档），勿放只读位置（启动时若目录不可写会弹提示）。
- 默认零联网：一期无任何网络代码；备份 JSON **不含邮箱授权码**。

### 备份与恢复

- 导出：设置 → 数据备份 → 导出备份，另存为 JSON（含分类/事项/字段定义与值，带版本号）。
- 导入：设置 → 数据备份 → 导入备份，选择 JSON → 二次确认 → 整库覆盖；**导入前状态可 Ctrl+Z 撤销恢复**；损坏或语义违规（如单选值不在选项内）的备份会被拒绝且当前数据不变。
- 换机/重装：整个目录拷贝到新位置即可；如需存档，用「导出备份」。

## 开发环境（源码运行）

- Node.js 18+；Rust stable（含 MSVC 工具链）；WebView2（Win10 1803+ / Win11 系统自带）
- 常用命令：
  - `npm install` 安装依赖
  - `npm run tauri dev` 开发运行（热更新）
  - `npx tauri build --no-bundle` 产出正式版 exe（`src-tauri\target\release\`）
  - `cargo test`（后端单测）与 `npm test`（前端 vitest）

# 日历待办工具

> Windows 桌面「日历 + 待办」二合一记录工具：按分类记录事项，根据时间字段完整性自动归入日历或待办展示。数据全本地、默认离线、免安装单 exe。

**当前状态：文档与原型阶段，软件尚未发布。** 下述功能为规划内容；正式可用版本发布后，本文件将补全安装与使用教程。

## 功能特性（规划）

**一期**
- 分类记录：预置生活/工作/娱乐/学习，可自定义增删改；分类颜色、重命名、删除（非空分类可选"连事项删除"或"移入未分类"）
- 日历视图：周/月切换、周一为每周第一天、月视图前后月补齐、事项以分类色圆角横条显示标题、跨格与跨月显示、同日堆叠与「+N」
- 待办视图：按截止时间升序，无截止沉底显示「未设截止」；纵向时间轴按年月分组，圆点可折叠
- 归属规则：开始+结束时间完整 → 日历；否则 → 待办；编辑时自动双向迁移
- 自定义字段：单行文本/多行文本/数字/日期/单选/多选；改类型按"能转则转、不能转清空"校验迁移历史数据
- 撤销/重做：Ctrl+Z 最多 10 步 + Ctrl+Y，仅当前会话有效
- 数据备份：导出/导入 JSON（不含邮箱授权码）

**二期（规划）**
- 邮箱绑定（SMTP 配置，授权码 Windows DPAPI 加密存储）
- 事项提醒 + 到点应用内提醒弹窗 + SMTP 直发邮件给自己（点击同步生成未来 30 天发送计划；关机错过不补发，启动时弹窗汇总告知）

完整需求见 [doc/PRD.md](doc/PRD.md)。

## 开发环境（工程初始化时需要）

- Node.js 18+；Rust stable（含 MSVC 工具链）；WebView2（Win10 1803+ / Win11 系统自带）
- 常用命令（工程初始化后可用）：
  - `npm install` 安装依赖
  - `npm run tauri dev` 开发运行
  - `npm run tauri build` 产出单个便携 exe（bundle targets = none）
  - `cargo test`（src-tauri 单测）与 `npx vitest`（前端单测）

## 数据与安全

- 数据库：exe 同目录 `data\calendar.db`；数据随目录走，删除目录即卸载干净。
- 默认零联网：一期无任何网络代码；二期仅"发送测试邮件"与"计划内提醒到点发送"两条路径联网（TLS）。
- 备份导出为 JSON，**不含邮箱授权码**；授权码在本机以 Windows DPAPI 加密存储。
